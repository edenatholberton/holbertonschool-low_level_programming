# C - Functions, nested loops

# The README for this project. 

- main.h: header file with the prototype of _putchar. 

- 0-putchar.c: prints _putchar, followed by a new line, using the _putchar function.
- 1-alphabet.c: function that prints the alphabet in lowercase, followed by a new line. - Used the same script from the previous project (task #2).
- 2-print_alphabet_x10.c: function that prints the alphabet 10x in lowercase, each followed by a new line.
- 3-islower.c: function that checks for a lowercase character, returning 1 if it is lowercase and 0 if it's not.
- 4-isalpha.c: function that checks for a letter; whether it is lowercase or uppercase, returning 1 if it is, and 0 if it is not.
- 5-sign.c: function that returns +1 if n is greater than zero, -1 if n is less than zero, or 0 is n is zero.
- 6-abs.c: function that computes the absolute value of an integer. Used if/else conditions.
- 7-print_last_digit.c: function that prints the last digit of a number and returns that digit. - used modulo again.
- 8-24_hours.c: function that prints each minute of the day, from 00:00 to 23:59, one per line. - ordered through putchar and modulo.
- 9-times_table.c: function that prints the 9 times table in a grid format, starting with 0.
- 10-add.c: function that adds two integers and returns the result.
- 11-print_to_98.c: function that prints the integers from n to 98, followed by a new line.
