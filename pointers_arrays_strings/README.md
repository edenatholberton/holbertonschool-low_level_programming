## C - Pointers, arrays and strings

- 0-reset_to_98.c: a function that takes a pointer to an int and changes the value it points to into 98.
- 1-swap.c: a function that swaps the values of two integers using pointers.
- 2-strlen.c: a function that returns the length of a string.
- 3-puts.c: a function that prints a string followed by a new line.
- 4-print_rev.c: a function that prints a string in reverse, followed by a new line.
- 5-rev_string.c a function that reverses a string.
- 6-puts2.c: a function that prints every other character of a string, followed by a new line.
- 7-puts_half.c: a function that prints the second half of a string, followed by a new line.
- 8-print_array.c: a function that prints n elements of an array of integers, followed by a new line.
- 9-strcpy.c: a function that copies a string from src into dest, including the ending null byte, and returns dest.
- 100-atoi.c: a function that turns a string into an integer, skipping the characters before the number and counting the minus signs to set the sign.


## C - More pointers, arrays and strings

- 0-strcat.c: joins the string src onto the end of the string dest and returns a pointer to dest.
- 1-strncat.c: joins at most n letters of the string src onto the end of the string dest and returns a pointer to dest.
- 2-strncpy.c: copies at most n bytes of the string src into dest, fills the rest of the n bytes with zero bytes, and returns a pointer to dest.
- 3-strcmp.c: compares the strings s1 and s2 and returns the difference of the first letters that differ, or 0 if the strings are the same.
- 4-rev_array.c: reverses the content of an array of integers in place.
- 5-string_toupper.c: converts the lowercase letters in a string to uppercase.
