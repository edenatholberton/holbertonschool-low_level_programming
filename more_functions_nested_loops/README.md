# C - More functions, more nested loops

# This is a readme doc that covers the all the projects tasks.

- 0-isupper.c: a script that checks if a character is uppercase or not.
- 1-isdigit.c: checks if a character is a digit (0 to 9)
- 2-mul.c: multiplies two integers
- 3-print_numbers.c: prints the numbers from 0 to 9, then a new line
- 4-print_most_numbers.c: prints the numbers from 0 to 9 except 2 and 4
- 5-more_numbers.c: prints the numbers 0-14 10 times.
- 6-print_line.c: draws a straight line of underscores
