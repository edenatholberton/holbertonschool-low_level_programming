This a README.md file that describes all the contents inside hello_world.

- 0-preprocessor: a shell script that runs the C file named in the CFILE variable through the preprocessor and saves the result in a file called c.
- 1-compiler: a shell script that compiles the C file named in the CFILE variable without linking, producing an object file with the same name and a .o extension.
- 2-assembler: a shell script that generates the assembly code for the C file named in the CFILE variable and saves it in a file with the same name and a .s extension.
