# C - malloc, free

- 0-create_array.c: creates an array of chars and fills it with a specific char.
- 1-strdup.c: returns a pointer to a new copy of a string.
- 2-str_concat.c: a function that joins two strings together into a new block of memory.
- 3-alloc_grid.c: a function that makes a grid of numbers in new memory, each set to 0.
- 4-free_grid.c: a function that frees a grid made by alloc_grid.
